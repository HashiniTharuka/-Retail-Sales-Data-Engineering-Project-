\# Retail Sales Data Engineering Project



\## Project Overview



This project focuses on building a Retail Sales Data Engineering pipeline using Python and PySpark. It aims to process raw retail sales data and organize it into structured data layers using the Medallion Architecture.



The project demonstrates practical data engineering concepts, including data ingestion, data processing, data transformation, and data quality management.



\## Technologies Used



\- Python

\- Apache Spark

\- PySpark

\- Pandas

\- CSV Data Processing

\- Git and GitHub



\## Project Architecture



The project follows the Medallion Architecture:



\- \*\*Bronze Layer:\*\* Stores raw data ingested from source CSV files.

\- \*\*Silver Layer:\*\* Processes, cleans, and validates raw data.

\- \*\*Gold Layer:\*\* Produces aggregated and business-ready datasets.
